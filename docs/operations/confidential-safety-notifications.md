# Confidential safety delivery

The moderation service submits an active signal to `POST /v1/internal/moderation-safety-signals` with `X-Grounds-Safety-Producer-Token`. The JSON object contains exactly `schemaVersion: 1`, `eventId`, `environment`, `signalRef`, `occurredAt` and `mode: ACTIVE`. IDs are canonical UUIDs and the timestamp is UTC. Stage and production each require an explicit `NOTIFICATIONS_SAFETY_{STAGE,PROD}_ENABLED=true` and a distinct `NOTIFICATIONS_SAFETY_{STAGE,PROD}_PRODUCER_TOKEN` (32–256 printable, non-space ASCII characters). Generate dedicated random credentials for each producer. The `gnc_` prefix belongs to general channel clients.

An accepted receipt is HTTP 202 with `{eventId, accepted: true}` after PostgreSQL commits. Identical retries return the same receipt. Reusing either identifier for a different event returns 409. Signals expire 24 hours after occurrence. Events already expired or over five seconds in the future are rejected. Storage admits at most 1,000 events per environment. A full store returns 503 for a new event.

A single scheduled invocation per instance leases one event at a time. It resolves recipients using the existing Forge internal token and `POST /v1/internal/moderation-safety-audiences/resolve`. Each request carries its schema version, environment, a fresh nonce, and an optional current user. Forge checks support access, the selected environment, and both Safety View and Receive. The response must match the nonce and environment, be less than five seconds old, and contain at most 1,000 recipients. An unavailable authority leaves delivery pending. The service checks the lease and freshness before committing one private notification and its deduplicated recipients together.

A verified JWT subject accesses `/v1/notifications/safety/{environment}`. GET returns `{items,nextCursor}` and accepts `limit` (1–50, default 25) and the previous private UUID cursor. GET `/unread-count` returns `{unreadCount}`. GET `/{id}` returns one item. POST `/{id}/read` and `/{id}/unread` return 204. Every operation checks current Forge authorization and private recipient membership. Unavailable authorization returns 404. Each item has fixed private copy, HIGH priority and an `OPEN_SAFETY_SIGNAL` action carrying only the environment and opaque signal reference. The ordinary inbox, SSE, Minecraft and administrative projections read their existing tables.

Both environment switches default off. Turning one off immediately hides its private APIs and stops audience processing for that environment. Retention maintenance continues through the service's existing datasource, removing up to 32 expired events and their private children per tick. This also removes records admitted before deactivation.
